# AgentDock Windows 原生桌面可视化安装版

**推荐下载的最新版（Windows x64 / AgentDock v0.7.9）**

[⬇️ 下载 AgentDockSetup-amd64.exe（约 104 MB）](https://github.com/asdfg3482968521-alt/agentdock/releases/download/agentdock-desktop-latest/AgentDockSetup-amd64.exe)

[SHA-256 校验文件](https://github.com/asdfg3482968521-alt/agentdock/releases/download/agentdock-desktop-latest/AgentDockSetup-amd64.exe.sha256)

安装：双击下载的 `AgentDockSetup-amd64.exe`，完成后从开始菜单打开 **AgentDock**，即可使用仓库原有的 WPF 可视化控制面板和系统托盘，而不是小型 PowerShell/CLI 启动器。

**注意：旧的 `AgentDock-OneClick-Windows.zip`（约 14 MB）是简易命令行启动包，不包含原生可视化面板，不要再分享那个链接。**

当前原生面板支持 Cloudflare Tunnel；**ngrok 尚未接入原生面板**。私有 GitHub 仓库的发布附件只有具备访问权限的用户能下载。

原生安装包超过 GitHub 仓库对单文件的限制，因此可执行文件存放于 GitHub Releases；这里保留长期有效的一键下载入口。
